📄 MinerU 文档解析

把 PDF / 图片 / 表格一键转成干净的文字与 Markdown

1 安装

  1. 双击 MinerU安装.exe，选择安装目录（默认 C:\MinerU_App）。
  2. 点击【开始安装】，耐心等待自动完成（首次约 10~20 分钟，需联网）。
  3. 看到"安装完成"提示后，桌面上会自动出现 「MinerU 文档解析」 快捷方式。
安装过程会自动检测你的电脑是否会下载并配置好所需组件，全程无需手动操作。请保持网络畅通，不要中途关闭窗口。

2 启动与使用

  1. 双击桌面的 「MinerU 文档解析」。
  2. 稍等片刻，浏览器会自动打开解析页面（第一次启动需加载约 1 分钟）。
  3. 把 PDF / 图片 / Word 等文件 拖进虚线区域，或点击选择文件。
  4. 选择 解析后端（推荐默认"快速 pipeline"），再点 开始解析。
  5. 完成后，结果文件会自动整理到输出目录，可直接查看 Markdown / 图片等。
屏幕右下角会出现一个小托盘图标。点它可随时：打开界面 / 重启服务 / 退出。程序常驻后台，不会打扰你。

3 常见问题

安装很慢 / 卡住了？

首次安装需下载约 3GB 组件，取决于网速。进度条会一直移动。若长时间无响应，可关闭后重新运行安装，支持断点续装。

为什么第一次解析特别慢？

首次启动需加载模型（约 1~2 分钟），之后会快很多。切勿在加载时反复点击。

想用"高精度"模式？

解析页面的后端若选"高精度 hybrid"，需要额外下载约 2GB 的模型。一般资料用默认快速模式即可。

解析结果在哪里？

默认在安装目录下的output文件夹，按批次存放。可在解析页面设置里修改输出位置。

不想用了怎么卸载？

删除安装目录文件夹，再删除桌面的快捷方式即可。不会残留系统设置。

若仍有问题，请把安装目录下的日志文件发给技术支持。
